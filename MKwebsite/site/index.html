    Learn Embedded RTOS in 20 Days¶

    From bare-metal to multi-RTOS mastery in 20 structured days.

    A comprehensive, hands-on guide to Real-Time Operating Systems for embedded engineers. Covers RTOS fundamentals, synchronization primitives, memory management, interrupt handling, timing analysis, and seven major RTOS implementations — all with C code examples, exercises, and cognitive-optimized learning features.

    Navigate the Course¶

    • Daily Lessons

      20 structured days from RTOS fundamentals to advanced implementations.

      Day 01–10: Core concepts — Tasks, Scheduling, Semaphores, Queues, Interrupts, Memory

      Day 11–18: RTOS deep dives — FreeRTOS, Zephyr, ThreadX, ChibiOS, embOS, NuttX, PX5, eCos

      Day 19–20: Comparison, selection guide, final project

    • RTOS Concepts

      Deep reference on the core concepts that underpin every RTOS.

      Scheduling · Synchronization · Memory · Interrupts · Timing

    • Patterns

    • RTOS Comparison

      Side-by-side comparison of 8 major RTOS options.

      Features · Footprint · Licensing · Certification · Use Cases

    • Cheatsheets

      Quick-reference API cheatsheets for every RTOS covered.

      FreeRTOS · Zephyr · ThreadX · ChibiOS · embOS · NuttX · PX5 · eCos

    Quick Reference — All 20 Days¶

    Day Topic Key Concepts
    01 Intro to RTOS Determinism, preemption, tasks, scheduler
    02 Tasks & Threads Task creation, priorities, states, stack
    03 Scheduling & Determinism Priority scheduling, round-robin, EDF
    04 Context Switching Register save/restore, latency, overhead
    05 Semaphores & Mutexes Binary/counting semaphores, mutex, priority inheritance
    06 Queues & Event Groups Message queues, event flags, mailboxes
    07 Interrupt Handling ISR design, deferred processing, NVIC
    08 Memory & Stack Management Heap strategies, stack sizing, memory pools
    09 Latency & Timing Analysis Jitter, WCET, response time analysis
    10 Build Systems & Board Bringup CMake, port layers, BSP, startup code
    11 FreeRTOS FreeRTOS API, tasks, queues, hooks
    12 Zephyr RTOS Zephyr kernel, devicetree, Kconfig
    13 ChibiOS ChibiOS/RT, HAL, thread API
    14 ThreadX Azure RTOS, GUIX, FileX integration
    15 embOS SEGGER embOS, compact footprint
    16 NuttX POSIX interface, filesystem, networking
    17 PX5 RTOS Ultra-compact, deterministic execution
    18 eCos Configurable components, HAL
    19 RTOS Comparison & Selection Feature matrix, decision framework
    20 Final Project Complete multi-task embedded application
